## 🗂️ Daftar Materi dan Rangkuman

### 1. Pengenalan Jurusan TIK PNJ dan Roadmap 2026–2030
Materi **Materi TIK mengajar_2026.pptx** menjelaskan visi Jurusan TIK untuk menjadi jurusan bertaraf internasional yang mendukung daya saing bangsa di bidang informatika dan komputer. Tiga misi utamanya adalah pendidikan vokasi, riset dan inovasi, serta tata kelola digital. Lima fokus pengembangan meliputi penguatan internal TIK, kerja sama institusi/industri, pengembangan SDM, sarana-prasarana/infrastruktur, dan inkubator bisnis TIK.

### 2. Struktur Organisasi Jurusan TIK
Materi **STRUKTURAL JURUSAN TIK.pdf** memperlihatkan Ketua Jurusan, Sekretaris Jurusan, Admin Jurusan, empat kepala program studi (TI, TMJ, TMD, RKS), serta kepala Laboratorium Komputer dan Jaringan dan Laboratorium Cyber Security. Kelompok Bidang Keahlian (KBK) mencakup RPL/SI, sistem cerdas, multimedia dan kecerdasan artifisial game, jaringan dan keamanan komputer, IoT, dan informatika sosial.

### 3. Kurikulum Merdeka, MBKM dan MSIB
Materi **TIK Mengajar.pptx** membahas MBKM sebagai kebijakan yang memberi kesempatan belajar di luar prodi dan MSIB sebagai jalur magang/studi independen bersertifikat. Delapan contoh kegiatan MBKM: pertukaran pelajar, magang, asistensi mengajar, riset, proyek kemanusiaan, wirausaha, proyek independen, dan membangun desa/KKN. Metode belajar yang dibahas meliputi **Project-Based Learning**, **Problem-Based Learning**, dan **Case-Based Learning**. **Catatan:** presentasi memuat angka berbeda mengenai jumlah semester di luar prodi pada beberapa slide; ketentuan administratif perlu dikonfirmasi ke prodi/sumber resmi.

### 4. Program Studi D4 Teknik Informatika (TI)
Menurut **Ti.pdf**, kurikulum OBE 2026 memuat **49 mata kuliah, 145 SKS, dalam 8 semester**. Profil lulusan meliputi analis solusi, pengembang aplikasi, penerap teknologi (data/AI/jaringan/cloud/keamanan), dan profesional kolaboratif. Kurikulum menggunakan pendekatan **Outcome-Based Education (OBE)**: perumusan dari profil lulusan, capaian pembelajaran lulusan (CPL), lalu mata kuliah.

### 5. Program Studi D4 Teknik Multimedia dan Digital (TMD)
Menurut **TMD.pdf**, kurikulum OBE 2026 memuat **55 mata kuliah dan 144 SKS**. Fokus keilmuan meliputi game, animasi, dan multimedia interaktif. Contoh profesi lulusan yang ditampilkan adalah digital content creator, multimedia designer, UI/UX designer, animator, game programmer, dan game developer.

### 6. Program Studi D4 Teknik Multimedia dan Jaringan (TMJ)
Menurut **TMJ.pdf**, kurikulum terdiri dari **8 semester, 144 SKS, 47 mata kuliah**. Profil keahlian mencakup jaringan komputer, IoT, infrastruktur TI dan keamanan, pengembangan aplikasi, serta technopreneur internet dan IoT. Materi **Matakuliah TMJ Kurikulum OBE 2026.pdf** memuat daftar mata kuliah terperinci; judul tabel internalnya bertuliskan *Kurikulum 2025*, sehingga versi berlaku perlu dikonfirmasi jika digunakan sebagai acuan akademik resmi.

### 7. Program Studi D4 Rekayasa Keamanan Siber (RKS)
Menurut **Daftar Mata Kuliah RKS.pdf**, contoh mata kuliah mencakup algoritma dan pemrograman, jaringan komputer, keamanan informasi dasar, pemrograman Python, ethical hacking, kriptografi, digital forensik, keamanan cloud, dan analisis malware. Pembelajaran memadukan teori dan praktik keamanan sistem informasi.

### 8. Pengenalan Laboratorium dan Tata Tertib
Menurut **Day-1-Pengenalan Akademik LAB TIK.pdf**, peminjaman alat dibedakan antara penggunaan **di laboratorium** dan alat **yang dibawa pulang**. Peminjaman ruangan memerlukan pengecekan jadwal, pengajuan, persetujuan Kepala Laboratorium, dan konfirmasi kepada teknisi/admin. Dokumen juga memuat ketentuan kedisiplinan, penampilan, perilaku akademik, dan sanksi.

## 🧠 Apa Itu Repository GitHub?
**Repository** adalah ruang penyimpanan proyek yang menampung berkas beserta riwayat perubahannya. **Git** adalah sistem version control, sedangkan **GitHub** adalah platform untuk menyimpan dan berkolaborasi pada repository Git secara daring.

**Fungsi repository:** menyimpan file, melacak perubahan (*commit*), mengatur pekerjaan melalui *branch*, bekerja sama, dan mempublikasikan dokumentasi. **Public repository** dapat dilihat siapa pun; **private repository** hanya dapat diakses pengguna yang diberi hak.

**Istilah yang dipelajari:**
| Istilah | Penjelasan |
| --- | --- |
| Repository | Tempat file proyek dan riwayat perubahan tersimpan |
| README.md | Halaman pengantar/dokumentasi utama berbasis Markdown |
| Commit | Catatan perubahan yang disimpan dalam riwayat proyek |
| Push | Mengirim commit dari komputer ke repository remote |
| Pull | Mengambil dan menggabungkan perubahan dari remote |
| Branch | Jalur pengembangan terpisah dalam proyek |
| Clone | Membuat salinan repository di komputer |
| GitHub Pages | Fitur untuk menerbitkan website statis dari repository |
